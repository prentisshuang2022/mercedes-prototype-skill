MB Corpo 网页字体资源包
整理日期：2026-10-20（Asia/Shanghai）

内容
本包包含奔驰美国官网公开加载的 6 种字形，每种提供 WOFF2 与 WOFF，共 12 个原始字体文件。
这是网页字体资源子集，未声称覆盖完整 MB Corpo 字库或桌面字体版本。
- A Text Condensed · Regular: MB Corpo A Text Cond Web / 400
- A Title Condensed · Regular: MB Corpo A Title Cond Web / 400
- S Text · Regular: MB Corpo S Text Web / 400
- S Text · Bold: MB Corpo S Text Web / 700
- S Title · Light: MB Corpo S Title Web / 300
- S Title · Bold: MB Corpo S Title Web / 700

使用
1. 保持 fonts 文件夹与 mb-corpo.css 的相对路径，打开 preview.html 查看效果。
2. 网页引入：<link rel="stylesheet" href="./mb-corpo.css">
3. 标题：font-family: "MB Corpo A Title Cond Web", Georgia, serif; font-weight: 400;
4. 正文：font-family: "MB Corpo S Text Web", Arial, sans-serif; font-weight: 400;
5. 正文强调使用 700；S Title 在本包提供 300 和 700 两个字重。
6. 本包为 WOFF/WOFF2 网页版本；需要桌面安装字体时，请向品牌方索取相应授权的桌面版本。
7. 不附中文字体；中文由项目另行配置的中文字体承接。
